# Active tasks — coordination-module

Claim work here **before** you start it. Another person's Claude Code may be editing the
same files right now, and git only tells you about that once there's already a conflict.

Move finished rows to the Done section rather than deleting them — it's the cheapest form
of "what changed lately" the group has.

**Status values:** `not-started` · `in-progress` · `blocked` · `done`
